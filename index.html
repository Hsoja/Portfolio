02 Sobre mí

Construyo software como se construye una casa: cimientos primero.

Desarrollo productos web de punta a punta, desde la API hasta el último píxel, con la seguridad como punto de partida y no como parche. Mi trabajo abarca asistentes de IA para negocios de servicios (FastAPI, React y LLMs), plataformas con autenticación robusta (Flask, Argon2id, CSRF) y portales estáticos ultrarrápidos con Astro.

En cada proyecto aplico la misma disciplina: pruebas automatizadas, Content Security Policy estricta, dependencias auditadas en CI, documentación clara y diseño accesible y responsive. Lo publico todo, incluido un reporte de seguridad por repositorio.
